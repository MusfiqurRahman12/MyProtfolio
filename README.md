# Musfiqur Rahman — Portfolio Website

> **SQA Engineer · AI Solution Architect · Consultant · PMP®**

An ultra-modern, high-performance personal portfolio website featuring a GPU-accelerated 300-frame scroll-driven canvas animation, sleek dark mode aesthetics, glassmorphic UI components, and comprehensive project case studies.

---

## ✨ Features

- **300-Frame Scroll Animation**: GPU-accelerated HTML5 `<canvas>` background driven by scroll inertia with linear interpolation (LERP).
- **Responsive & Modern Design**: Crafted with pure Vanilla CSS, geometric typography (`Plus Jakarta Sans`), and glassmorphism.
- **Dynamic Role Rotator**: Seamless transition between *SQA Engineer*, *AI Solution Architect*, and *QA & AI Consultant*.
- **Featured Projects**:
  - [AI Test Case Generator](https://github.com/MusfiqurRahman12/ai-test-case-generator) — AI-powered test generation syncing with Jira, Trello & ClickUp.
  - Accelvia Content Protection — WordPress security plugin.
  - Surgery South — Healthcare E2E test automation suite with Playwright & Selenium.
  - Condosales Platform — High-concurrency API and load benchmarks with Postman & JMeter.
  - Sixth & Rio — Pixel-perfect cross-browser and layout QA.
  - Accelvia CTA Builder — WordPress call-to-action banner & button builder.
- **Track Record & Skills**: Comprehensive work experience timeline, technical skills matrix, and professional certifications (PMP®, PMI Agile®, SDET).

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/MusfiqurRahman12/MyProtfolio.git
   cd MyProtfolio
   ```

2. Start the local server:
   ```bash
   node server.js
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:5173/
   ```
